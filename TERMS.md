# Terms of use — Bioplot

Last updated: 2026-09-03

Bioplot is a free, unofficial planning tool for Chainers Farm. It is **not affiliated with,
endorsed by, or connected to Chainers** in any way.

## What it does

It reads your farm from your own browser and calculates what to plant. It is an analysis tool.
It never acts on your account: no planting, harvesting, buying, merging, or signing.

## What it does not promise

The numbers come from the game's public documentation and, when captured, the game's own
catalogue endpoints. Game balance changes, and an undocumented API can change shape without
notice. Plans are estimates, not guarantees, and criticals and lamp upgrades are dice: the
tool reports a range for exactly that reason.

You are responsible for what you do with the advice. The software is provided "as is", without
warranty of any kind.

## Your account is your responsibility

Using any third-party tool alongside a game may be restricted by that game's own terms. Read
Chainers' terms and decide for yourself. This tool deliberately stays read-only to keep that
decision as low-risk as it can be, but the decision is still yours.

## Checking the claims

The source is published at https://github.com/develoverli/bioplot under the MIT licence, so the
claims on this page are yours to check rather than to trust. A browser extension is also
installed as ordinary, unminified JavaScript: open `chrome://extensions`, turn on Developer
mode, and read it. Your own browser's network tab shows the rest from the outside. If what the
code does and what this page says ever disagree, the code is the truth and this page is a bug
worth reporting as an issue.
