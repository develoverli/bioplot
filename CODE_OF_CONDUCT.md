# Code of conduct

Bioplot is a small project, and this is a short document. It applies everywhere the project
happens: issues, pull requests, discussions and reviews.

## The standard

Be direct and be decent. Disagree with the code, not the person. Concretely:

- Assume good faith, and ask before you conclude.
- Review the change in front of you. A blunt "this is wrong, here is why" is welcome;
  "you are wrong" is not.
- Respect people's time: one issue per problem, one change per pull request, and a
  reproduction when you say something is broken.
- No harassment, no insults, no discrimination of any kind, no publishing anyone's private
  information. This includes other players' farm data: never post a capture that is not yours.

## Enforcement

Maintainers may edit, hide or delete contributions that break this, and may block repeat
offenders. Report a problem by opening an issue that says only "conduct, please contact me"
and a maintainer will reach out privately.
